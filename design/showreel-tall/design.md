# HYDLNK showreel — design spec

- Background: #1C1B1A (charcoal). Raised panels #2A2825, lines #45413B.
- Foreground text: #F4F3F0; muted #A9A49B / #B9B4AB.
- Accent: brass #B8914F (highlights, marks, bars); brass light #D9B877.
- Positive: #2F7D4F on #E7F3EC.
- Type: Public Sans 600/700 for headlines and UI; Geist Mono 400/500 for labels, tokens, URLs.
  Tenant fonts (Fraunces, Instrument Serif, Geist) only inside the demo page.
- Shape: 6-12 px corners on UI; circles only for avatars and status dots.
- Do: one accent, generous negative space, decisive eases. Don't: gradients on text, neon, grain.
